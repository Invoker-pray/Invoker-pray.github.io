local LLM deploy - deepseek - section1

Created2025-05-28|Updated2025-09-20
|Post Views:

why local LLM model?

  • I was frustrated when DeepSeek server busy, and local model is much more secure, and sometimes there a some inexplicable banned word make all conversation unpleasant.

  • I want a model that can alway meet my requirement, like translate papers, analysis some innovative approchs, I need it to be specified for me.

so I nead a local LLM, and to adjust it for myself.

how to deploy?

ollama may be the easiest way

ollama is a tool that deploy local LLM, you can use it deploy LLM with some very clear and short command.

and you can use Modelfile to create you own model.

you can use API to invoke you model.

what should we do when finish the pull

some explanation about ollama’s conversation

ollama’s conversation is non-interacted, so you should save history_chat by yourself, and if you want to resume, you should pass your record in.

but that is troublesome and primitive, we can do this more elegent(with python).

optional: use GPU

if ollama use only CPU, LLM will be slow and the computer will be very hot.

so we need to use GPU to deal with this.
